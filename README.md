Documents légaux publics de l’application **Xplor** (App Store / conformité).

## 📄 Documents disponibles

- [Politique de confidentialité](./PRIVACY_POLICY.md)

## 🌐 URL publique (Apple App Store Connect)

Ce dépôt est publié pour fournir une URL publique de la politique de confidentialité requise par Apple.

Une fois GitHub Pages activé, utilise :

- `https://<github-username>.github.io/xplor-legal/` (si `index.md` ou `index.html` existe)
- ou directement :
  `https://<github-username>.github.io/xplor-legal/PRIVACY_POLICY`

> Si tu n’utilises pas GitHub Pages, tu peux aussi fournir l’URL du fichier dans le repo :
> `https://github.com/<github-username>/xplor-legal/blob/main/PRIVACY_POLICY.md`

## ⚙️ Mise en place rapide

1. Créer le repo **public** `xplor-legal`
2. Ajouter ce `README.md`
3. Ajouter `PRIVACY_POLICY.md`
4. (Recommandé) Activer **GitHub Pages** :
   - Settings → Pages
   - Source: `Deploy from a branch`
   - Branch: `main` / root
5. Copier l’URL publique dans App Store Connect → Privacy Policy URL
